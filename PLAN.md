# AHelperW — план реализации

Аддон для WoW 12.1: настраиваемое перетаскиваемое окно с супер-контрастными квадратами состояния способностей и цифрами здоровья/ресурсов, профили под каждый класс/спек.

Ресерч: `docs/research-design.md`, `docs/research-api.md`, `docs/research-classes.md`.

## Утверждённые решения
- Зелёный квадрат = готово, тёмно-красный = на КД (+ янтарный «вот-вот», синий «нет ресурса»).
- Здоровье/непрерывные ресурсы — цифры; альтернативные ресурсы — **гибрид**: цифра в квадрате, квадрат тёмный при 0 / янтарный / ярко-зелёный на максимуме.
- Непрозрачная чёрная подложка, шрифт JetBrains Mono ExtraBold (bundled .ttf).

## Структура файлов
```
AHelperW/
├── AHelperW.toc          # Interface: 120100, SavedVariables: AHelperWDB
├── Media/JetBrainsMono-ExtraBold.ttf
├── Core.lua              # инициализация, события, SavedVariables, спек-детект
├── Layout.lua            # фрейм, подложка, пиксель-чёткость, drag&drop, масштаб
├── Squares.lua           # квадраты способностей: состояние/цвет/заряды/вспышка
├── Resources.lua         # HP, первичный ресурс, гибрид-счётчик, руны
├── ClassData.lua         # маппинг spec → списки spellID (из research-classes.md)
├── Palette.lua           # палитры (default / colorblind), пороги
└── Options.lua           # /ahw: разблокировать/масштаб/палитра/секунды на КД
```

## Этапы
1. **Каркас**: TOC + Core + Layout — окно с подложкой, drag, сохранение позиции, /ahw lock|unlock.
2. **Квадраты**: Squares.lua — ряд квадратов по ClassData текущего спека; состояние через `cd.isActive`/`isOnGCD` (NeverSecret-булевы — работают в бою), тикер 0.1s на перекраску, вспышка AnimationGroup.
3. **Ресурсы**: HP% и первичный ресурс через SetText + ColorCurve (Secret-safe), гибрид-квадрат для вторичных (не секретны — обычная логика), руны через GetRuneCooldown.
4. **Маппинг классов**: ClassData на все 40 спеков; рантайм-валидация spellID (неизвестные скрывать), выбор способностей и порядок — override в SavedVariables.
5. **Полировка**: CVD-палитра, секунды ≤10s через Cooldown-виджет, PLAYER_SPECIALIZATION_CHANGED, масштаб 1440p/4K.

## Ограничения Midnight (Secret Values) — учтено
В бою числа КД/HP/маны — «секреты»: без арифметики/сравнений. Дизайн опирается на NeverSecret-булевы (isActive, isOnGCD, isEnabled) и санкционированные виджеты (SetText, SetVertexColorFromBoolean, ColorCurve, Cooldown). Вторичные ресурсы не секретны. Подробно: docs/research-api.md.

## Продолжение: профили HUD из APL

- Основная кнопка аддона и /ahw config: настройки вида/положения и экспорт (реализовано в 0.2.13; ожидается просмотр в клиенте).
- Ручной редактор: раздел «Диагностика» и /ahw editor, сохранён для исследования и исключений.
- Следующая отдельная задача: генератор состава HUD из закреплённой версии APL и выбранных талантов. Нужен явный каталог соответствий action/buff/debuff → cast/aura spellID, включая overrides и неподтверждённые соответствия.
- Генератор должен сохранять порядок и геометрию, выявлять неизвестные зависимости и требовать новый экспорт при изменении состава. Не считать текущий набор автоматически сгенерированным из APL.

## Решение пользователя — 28 сентября 2026

- Расширение на другие классы/спеки пока **отложено**. Сейчас не начинать перенос.
- Рабочая связка экспорта, ридера и APL — Arms/Slayer. HUD других классов
  частично готов к отображению, но не является готовой поддержкой их APL.
- Сохранена оценка и план: [docs/multispec-roadmap.md](docs/multispec-roadmap.md).
  Ориентир: 6–12 инженерных дней на общую основу, затем 4–8 на простой DPS.
  Это предварительная трудоёмкость, не обещанный срок. Fury — кандидат для
  пилота, а не утверждённый следующий спек.
- Текущий приоритет — первый приватный Windows-релиз установщика.
