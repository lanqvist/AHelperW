# Проверка доступности данных о соседних целях

Диагностика добавлена в установленный аддон. До записи в игре пригодность автоматического подсчёта не подтверждена.

1. Остановить исполнение ридера (F8), выполнить `/reload`.
2. Включить вражеские полосы здоровья. Выделить манекен рядом с группой.
3. Вне боя выполнить `/ahw targetprobe start`.
4. За 30 секунд вступить в бой, приблизиться к группе, отойти и вернуться. Повернуть камеру, чтобы проверить зависимость от видимых неймплейтов.
5. После сообщения об окончании выполнить `/ahw targetprobe report`, скопировать Ctrl+A / Ctrl+C и прислать отчёт.

`/ahw targetprobe stop` завершает запись раньше. Последняя запись хранится в `AHelperWDB.targetProbe`; `/reload` или выход из игры сохраняет её в SavedVariables. Новая запись заменяет предыдущую. Не более 31 снимка, один снимок в секунду.

Проверяются текущая цель и токены неймплейтов: стандартные слоты 1–40 плюс токены, полученные событиями появления. Сохраняются только открытые булевы ответы либо метки nil / secret / error / missing; секретные значения не сравниваются и не сохраняются.

В отчёте MS — проверка дистанции «Смертельного удара», Cleave — «Рассекающего удара». Число подтверждённых ближних неймплейтов не является точным количеством врагов в радиусе AoE: возможны разные радиусы, направление удара, невидимые полосы, нейтральные/не участвующие в бою цели. Отдельно записываются враждебность, смерть, участие в бою и совпадение с текущей целью.

Диагностика не изменяет число целей в HUD или условия APL. Решение об автоматическом режиме принимается после сравнения записей вне боя / в бою / при смене дистанции и камеры.
