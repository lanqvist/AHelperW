# Расширение на другие специализации: предварительная оценка

Обновление 28 сентября: пользователь разрешил ВВ/Шадо-Пан как второй профиль.
Реестр профилей, экспорт ресурсов и адаптер APL добавлены в рабочую копию;
игровая проверка ещё не выполнена. Текущий статус — `windwalker-apl/README.md`.
Ниже сохранён исходный аудит до этих изменений; перечисленные ограничения
нужно сверять с текущим кодом. Остальные новые спеки пока отложены.

Оценка по текущему исходному коду, 28 сентября 2026. Диапазоны — инженерные
дни одного разработчика на один билд/hero tree фиксированного клиента,
с доступом к персонажу для проверки. Это не обещание календарного срока.

## Что уже общее

Геометрия HUD, захват изображения, распознавание цветов и чисел, хранение
назначений, журнал событий и подтверждение применений. Наборы отображения
для других специализаций уже присутствуют; готовых ротаций это не означает.

## Что надо обобщить

- `Export.lua`: ограничение spec 71, Slayer, алиасы и эталон дальности.
- `Resources.lua`: регионы вторичных ресурсов и рун; сейчас основной регион
  имеет имя `rage`, здоровье цели/GCD подключены для Arms.
- `CombatContext.lua`, `TargetCount.lua`: ресурс и проверки дистанции Warrior.
- `reader/apl.py`: словари действий/аур, таблица талантов, доступные переменные,
  отчёт о неподдерживаемых действиях и параметрах APL.
- `reader.py`, `ocr_plan.py`: подключение профилей спеков и приоритеты чтения.
- Исполнение: политика GCD/off-GCD, каналы, empowered casts, действия на союзника
  и на область; текущий механизм не покрывает все эти случаи.

## Оценка

| Объём | Инженерные дни |
|---|---:|
| Общая основа и сохранение работы Arms | 6–12 однократно |
| Простой DPS после общей основы | +4–8 на спек |
| Сложный DPS: несколько ресурсов, питомцы, DoT, каналы, выбор целей | +12–25 на спек |
| Танк: только атакующая ротация | +6–12 на спек |
| Танк: активная защита с доступными данными об угрозах | ещё +10–20 |
| Хилер: ограниченная помощь для выбранного союзника | +10–20 |
| Первый прототип лечения группы из пяти человек | +30–60, после проверки реализуемости |

Первый простой DPS с общей основой: примерно 10–20 инженерных дней.
Новые недоступные в бою данные могут увеличить оценку или ограничить объём.
Нельзя экстраполировать эти цифры линейно на все спеки и обещать полноценное
лечение или защиту по наличию DPS APL. Актуальное внешнее покрытие SimC в этой
оценке отдельно не проверялось.

Порядок: аудит Fury как близкого пилота → общие профили и отчёт покрытия →
рекомендации с причинами Unknown → проверка исполнения → второй пилот
с другим ресурсом. Автоматическую сборку набора HUD из зависимостей APL
реализовать в общей основе. Танковую защиту и лечение вести отдельно.
