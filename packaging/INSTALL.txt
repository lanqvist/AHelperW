AHelperW 0.3.0 — первый выпуск для Windows x64

Состав: аддон WoW, ридер, Python, OCR-модели и зависимости.
Отдельно устанавливать Python или AutoHotkey не нужно. После установки
ридер работает без загрузки моделей из интернета.

Первый запуск
1. Установи компоненты. Для аддона укажи World of Warcraft или _retail_.
   Чтобы поставить только ридер, сними компонент аддона.
2. В WoW включи AHelperW. Вне боя: /reload, затем /ahw config.
   Для Arms/Slayer: /ahw armsapl. Компактный вид: /ahw compact on.
3. Настрой положение HUD, выполни /ahw export, скопируй весь JSON
   и сохрани в текстовый файл UTF-8.
4. Запусти AHelperW из меню Пуск. «Открыть экспорт» — выбери файл.
5. Настрой клавиши. Убедись, что они совпадают с панелями WoW.
6. Чтение запускается кнопкой «Начать». Автонажатия включаются отдельно;
   при запуске программы они выключены. F8 останавливает чтение/исполнение.

После перемещения или изменения масштаба HUD нужен новый экспорт.
Профили, назначения и логи: %LOCALAPPDATA%\AHelperW.
Личные данные разработчика в установщик не включены.

Ограничения первого выпуска
APL предназначена для Arms/Slayer и клиента 12.1.0.69933. Наличие HUD для
других специализаций не означает поддержку их APL. Неизвестные данные
могут приостанавливать выбор действия. Наборы пока не генерируются из APL
полностью автоматически. Автоматическое управление игрой может нарушать
правила Blizzard и приводить к санкциям.

Обновление и удаление
Закрой ридер перед обновлением. Установщик предложит закрыть занятую копию.
Существующий аддон копируется в Backups внутри папки приложения.
Удаление через настройки Windows убирает ридер, но сохраняет пользовательские
данные, резервные копии и аддон. Аддон при необходимости удаляется вручную
из _retail_\Interface\AddOns\AHelperW. Настройки WoW/WTF не меняются.
