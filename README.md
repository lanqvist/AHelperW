# AHelperW

**Для продолжения разработки:** [память проекта](docs/PROJECT_MEMORY.md)
содержит актуальную архитектуру, особенности APL/API, историю проверок,
ограничения и состояние релиза. Правила входа в проект — [AGENTS.md](AGENTS.md).

Супер-контрастный HUD для World of Warcraft 12.1 (Midnight): состояние способностей — цветными квадратами, здоровье и ресурсы — цифрами, альтернативные ресурсы — гибридом «цифра в квадрате». Профили под все 40 спеков.

В репозитории находятся аддон и Windows-ридер. Исполнение APL в ридере сейчас ориентировано на Arms/Slayer и клиент 12.1.0.69933; наличие наборов других специализаций не означает поддержку их APL.

Личные экспорты HUD, назначения клавиш, журналы, окружение Python и локальное состояние не входят в репозиторий. После клонирования нужен собственный экспорт. Инструкции ридера: [reader/README.md](reader/README.md).

## Установочный пакет для Windows

Пакет **0.4.1** включает аддон **0.2.15**, ридер, Python и OCR-модели.
Установщик публикуется в [Releases](https://github.com/lanqvist/AHelperW/releases).
Для закрытого репозитория нужен доступ к GitHub; скачанный установщик можно
передавать отдельно вместе с включёнными исходниками и лицензиями.
Выбери папку WoW, затем импортируй собственный экспорт HUD и назначь клавиши.
В установленном ридере чтение и автонажатия изначально выключены.
Данные хранятся в `%LOCALAPPDATA%\AHelperW`. Подробности:
[инструкция установки](packaging/INSTALL.txt), [сборка из исходников](packaging/README.md).

## Установка

1. Скопируй папку `AHelperW` (ту, где лежит `AHelperW.toc`) в `World of Warcraft\_retail_\Interface\AddOns\`.
2. Шрифт JetBrains Mono уже включён в `AHelperW\Media\` вместе с лицензией OFL.
3. Перезапусти игру или сделай `/reload`.

## Команды

| Команда | Действие |
|---|---|
| `/ahw unlock` | разблокировать окно и перетащить мышью |
| `/ahw lock` | закрепить (клики проходят сквозь окно) |
| `/ahw dock left\|right\|off` | расположить у края; `off` возвращает сохранённую свободную позицию |
| `/ahw scale 1.5` | масштаб (0.5–3); для 4K рекомендуется ~1.5 |
| `/ahw alpha 0.9` | прозрачность чёрной подложки (0–1) |
| `/ahw palette cvd` | палитра для дальтоников (циан вместо зелёного); `default` — обратно |
| `/ahw cdtext on` | секунды на кулдаунах |
| `/ahw reset` | вернуть окно к левому краю |
| `/ahw spells` | показать набор текущего спека |
| `/ahw add 190319` / `/ahw del 190319` | добавить/убрать способность (spellID с wowhead) |
| `/ahw addproc 48108` / `/ahw delproc 48108` | добавить/убрать прок (ID ауры бафа) |
| `/ahw adddebuff 1943` / `/ahw deldebuff 1943` | добавить/убрать свой дебафф на цели |
| `/ahw default` | вернуть дефолтный набор спека |
| `/ahw config` | настройки вида, положения и экспорта (также кнопка у миникарты) |
| `/ahw editor` | ручной менеджер способностей/проков/дебаффов; также доступен в диагностике |
| `/ahw compact on\|off` | компактная или полная раскладка; после переключения обновить экспорт |
| `/ahw icons on\|off` | иконки внутри квадратов (цвет остаётся главным) |
| `/ahw auratimers on\|off` | таймеры действия баффов/проков |
| `/ahw armsapl` | дополнить набор под сохранённый билд Arms/Slayer 69933, включить таймеры; вне боя |
| `/ahw preview on\|off` | показать иконки и номера квадратов с компактной легендой справа; переключать вне боя |
| `/ahw context on\|off` | дополнительный контекст Arms: цели, касты, дистанция, время, предметы |
| `/ahw targets 1\|2\|3\|unknown` | ручной режим числа целей (3 означает 3+); также ЛКМ/ПКМ по ячейке |
| `/ahw ttd 60`, `/ahw fight 120` | ручные прогнозы времени смерти цели/конца боя; `unknown` очищает |
| `/ahw potion itemID` | выбрать зелье (можно перетащить из сумки на слот); 0 очищает |
| `/ahw trinket 1 buff 120 20 strength` | пример задания metadata тринкета: слот, вид эффекта, КД, длительность, сила |
| `/ahw stable on\|off` | постоянные цвета без вспышек; по умолчанию включено |
| `/ahw export` | статический JSON расположения HUD, ID, цветов, текущих талантов и экипировки |

## Цветовой язык

- **Ярко-зелёный** — КД завершён, проверка применимости пройдена; при наличии диапазона проверяется дистанция до цели. Линия видимости не проверяется.
- **Янтарный** — откатится в ближайшие 1.5 сек (вне боя; в бою см. ограничения)
- **Тёмно-красный** — на перезарядке
- **Синий** — откачена, но не хватает ресурса
- **Серый ×** — откачена, но сейчас неприменима (например, Казнь без условий).
- **Оранжевый Д** — цель вне диапазона способности.
- **Тёмно-янтарный ?** — данных не хватает. Не означает ни готовность, ни отсутствие баффа.
- Цифра в углу квадрата — заряды (Fire Blast, Shield Block и т.п.)
- Гибрид-квадрат: тёмный при 0, янтарный 1–4, ярко-зелёный на максимуме — «трать!»
- Руны ДК — 6 мини-квадратов, каждая зелёная/тёмная
- **Маджента** — квадрат-прок: бафф висит (Hot Streak, Killing Machine, Enrage…), с цифрой стаков; тёмный — прока нет. Дефолтные наборы проков собраны по APL (SimC midnight) на все 40 спеков; рендерит движок через AuraContainer — работает и в бою, несмотря на Secret Values
- **Фиолетовый** — свой ДоТ/дебафф висит на текущей цели (Rupture, Agony, Ignite…), внутри — движковый отсчёт оставшихся секунд и стаки; тёмный — дот отвалился или цели нет
- Для Arms под ресурсами — полоса здоровья цели с отметками 20% и 35%, рядом GCD: зелёный готов, красный активен. Значения передаются в штатные виджеты WoW даже при Secret Values.

Подробное покрытие Arms/Slayer APL и оставшиеся ограничения:
[docs/arms-apl/README.md](docs/arms-apl/README.md).
Новый блок показывает наблюдаемые состояния и явно отмеченные ручные настройки.
Наличие HUD не подтверждает полноту APL или точность внешнего распознавания.

## Ограничения Midnight (Secret Values)

Blizzard в 12.0 закрыла аддонам «сырые» числа в бою. Что это значит здесь:

- Готово/на КД, заряды-как-текст, руны и все альтернативные ресурсы — работают везде, включая бой.
- Янтарное «вот-вот» и цветовые пороги здоровья — только вне рестрикций (вне боя/энкаунтеров); в бою цифра ХП белая, но отображается всегда.
- Секунды на кулдаунах рисует штатный Cooldown-виджет (единственный разрешённый путь) — он показывает отсчёт всю длительность, а не только <10 сек.

## Структура

- `Core.lua` — события, тикер обновления, инициализация
- `Layout.lua` — окно, подложка, перетаскивание, пиксель-чёткость, шрифты
- `Squares.lua` — квадраты способностей (состояние, заряды, вспышка)
- `Resources.lua` — здоровье, ресурс, гибрид-счётчик, руны
- `Display.lua` — нативное форматирование секретных чисел
- `CombatContext.lua` — контекст Arms, касты, предметы и ручные прогнозы
- `Export.lua` — статический JSON схемы HUD и профиля
- `ClassData.lua` — маппинг спеков на способности (spell ID из ресерча 12.1, см. `docs/research-classes.md`)
- `Palette.lua` — палитры default/cvd
- `Options.lua` — команды `/ahw`

ID, помеченные в ресерче как неподтверждённые, при отсутствии в клиенте автоматически скрываются (рантайм-валидация через `C_Spell.GetSpellInfo` + `IsPlayerSpell`).
