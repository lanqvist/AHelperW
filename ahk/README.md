# Назначение клавиш Havoc

1. Установи [AutoHotkey v2](https://www.autohotkey.com/).
2. Запусти `HavocBindings.ahk` двойным щелчком.
3. Выбери способность, нажми её игровое сочетание в поле и нажми «Назначить».
4. Нажми «Сохранить профиль».

Редактор содержит способности из текущего Havoc-набора AHelperW и базовые атаки.
Ненужные таланты оставь без клавиши. Названия — подписи редактора, соответствие
строится по spell ID. Для замен в метаморфозе назначается общая клавиша исходной
способности. Проки и дебаффы не имеют самостоятельной клавиши применения.

Профиль автоматически загружается из `profiles/havoc.ini`. Сохранение проверяет
повторяющиеся сочетания. Формат сочетаний AHK: `^` — Ctrl, `!` — Alt, `+` — Shift.
Поле Hotkey рассчитано на клавиатуру, без кнопок мыши и сочетаний с Win.

Пример файла после назначения:

```ini
[profile]
schemaVersion=1
specId=577
name=Havoc
keyFormat=AHK-v2
[bindings]
198013=^1
188499=2
```

Это редактор биндов: чтение HUD, расчёт APL и отправка клавиш пока не подключены.
Порядок строк не задаёт приоритет ротации. Метаморфоза требует выбора места;
одного бинда недостаточно, чтобы определить её поведение при применении.

Документация: [GUI и Hotkey](https://www.autohotkey.com/docs/v2/lib/GuiControls.htm#Hotkey),
[INI](https://www.autohotkey.com/docs/v2/lib/IniWrite.htm).
